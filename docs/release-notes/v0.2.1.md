MARS IDE v0.2.1 makes running programs in the browser more dependable: Stop and Pause now work
on every press and react almost at once, the run bar no longer shifts under your finger, and the
simulator is faster.

## Get it

- **Use it online:** <https://franticplant.github.io/mars-ide/>. Close every MARS IDE tab and
  open it again to switch to this version.
- **Download and double-click:** `mars-ide.html` below is the entire IDE in one file. Open it in
  your browser; no internet needed. Files you kept in an older copy stay with that copy, so
  export them there and import them here.
- **Host it yourself:** unpack `mars-ide-static-v0.2.1.tar.gz` onto any static file host, or run
  `podman run --rm -p 127.0.0.1:8081:8080 ghcr.io/franticplant/mars-ide-static:v0.2.1`.

## Fixed

- **Stop and Pause register every time.** A press could be lost while a program was running,
  because the button was redrawn between pressing and releasing it.
- **Stop and Pause react fast,** in well under a second (typically 15-110 ms), even while a
  program floods the console. Nothing printed before the stop is lost.
- **The run bar holds still.** Buttons and the status pill keep their size and position as the
  program state changes; on phones, Back/Stop is always in the same place.

## Faster

- The browser simulator runs about 1.6 million instructions per second, up from 1.3.

## Release files

- The `mars-ide-<tag>-arm64.tar` image archive is no longer attached. The container images on
  `ghcr.io` are still published for amd64 and arm64.
