MARS IDE v0.2.0 turns the browser IDE into a real workspace: split the editor into panes, preview
Markdown notes with diagrams beside your code, and see register and memory values right where
you read the code. It also comes as a single file you can download and double-click: the whole
IDE, offline, with nothing to install.

## Get it

- **Use it online:** <https://franticplant.github.io/mars-ide/>. If you used v0.1.0 there,
  close every MARS IDE tab and open it again to switch to this version.
- **Download and double-click:** `mars-ide.html` below is the entire IDE in one file (3 MB).
  Open it in Chrome, Edge, Firefox or Safari; no internet needed. Your files are kept by the
  browser for that copy, so export a backup now and then.
- **Host it yourself:** unpack `mars-ide-static-v0.2.0.tar.gz` onto any static file host, or run
  `podman run --rm -p 127.0.0.1:8081:8080 ghcr.io/franticplant/mars-ide-static:v0.2.0`.

## New: one-file IDE

- **`mars-ide.html`.** Download it, double-click it, and the IDE opens in your browser from
  disk: editor, simulator, reference card and PDF, Markdown preview. Copy it to a USB stick
  or a lab machine; it never talks to a server.

## New: split editor and Markdown

- **Editor groups.** Drag a tab to a pane's edge to split it, or into a pane to move it; up to
  eight panes in nested splits, resizable with the mouse or the keyboard. The **⋯** menu does the
  same without dragging, for touchscreens. The layout is restored when you come back.
- **Markdown preview** beside the source, live as you type: tables, task lists, highlighted
  code, local images and Mermaid diagrams, in your IDE theme. Keep assignment notes or a
  write-up next to the program it describes.
- **Zen keeps your layout.** F10 hides the IDE chrome but leaves your panes as they are;
  maximizing a single pane is a separate toggle.

## New: values where you read the code

- **Ctrl/Cmd+click** a register, label or number in the editor for a small card with its current
  value, what it points to (label, memory region, string) and its role.
- **Scope values:** Ctrl+Shift+; shows a faint summary of the registers used in the current
  labelled block, readable or in hex.
- **Values inspector** for the instruction about to run, including a load or store's effective
  address and the memory word there.
- **Reference card examples:** tap an instruction on the card for a short commented example.

## Changes

- **File history.** Saved versions, drafts and deleted files are kept per file; restore any of
  them as a new copy. **Export full backup with history** saves everything as one ZIP.
- **Safer storage.** Files are checksummed, damaged storage stops the IDE instead of being
  overwritten (with a recovery download), and a save never silently replaces a file another
  tab or your program changed.
- **Updates wait for you.** A new version no longer takes over a tab you are editing in; it
  applies when you next open the IDE.
- **Keys:** Shift+F12 resets, F11 toggles fullscreen, Shift+F11 stops. Optional Emacs-style
  movement keys (Settings). Ctrl+F8 or F4 toggles a breakpoint, also with line numbers hidden.
- **Panels:** on wide screens, the console and the registers have their own show/hide buttons.
- **Phones:** the bottom navigation stays at the bottom while the keyboard is open.

## Under the hood

- **Hardened previews.** Markdown renders in an isolated sandbox that cannot reach your files,
  and remote images load only when you allow them for that preview.
- **Stricter site security policy** on the website and the self-hosted image.
- **Containerised builds:** every build and test step runs in rootless containers.
- **Experimental WasmGC engine** build (`make static-wasm`), for comparison only; the JavaScript
  engine remains the default.
