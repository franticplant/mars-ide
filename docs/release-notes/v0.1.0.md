MARS IDE's first release: the MIPS Assembler and Runtime Simulator (MARS 4.5) as a modern IDE
that runs entirely in your browser, on desktop and phone, with no install and no server. The
real MARS engine runs inside the page, so programs assemble and run exactly as they do in the
original MARS.

## Get it

- **Use it now:** <https://franticplant.github.io/mars-ide/>. It works offline after the first
  visit, and you can install it as an app from the browser menu. Your files stay in your browser.
- **Host it yourself:** unpack `mars-ide-static-v0.1.0.tar.gz` onto any static file host, or run
  the image: `podman run --rm -p 127.0.0.1:8081:8080 ghcr.io/franticplant/mars-ide-static:v0.1.0`
  and open <http://127.0.0.1:8081>.
- **Terminal UI:** `ghcr.io/franticplant/mars-ide:v0.1.0` (see the README for the `podman run`
  line). This image also contains the older self-hosted web server; the static site above is the
  recommended way to use the web IDE.

## New: a MIPS IDE in the browser

- **Editor made for MIPS.** Syntax colours (pseudo-instructions are shaded differently from real
  ones), completion, a hint bar with the syntax and meaning of the instruction under the cursor,
  and errors underlined at their source line.
- **Watch it run.** Step, step back, run at a chosen speed, pause, and breakpoints. The current
  line, the trail of recently executed lines and changed registers and memory are highlighted
  as they change.
- **Values that explain themselves.** Click a register or memory word to see what it means right
  now (the syscall `$v0` selects, a pointer's target, a string, a return address) in every
  format, and edit it.
- **Everything MARS has.** Registers (GPR, Coprocessor 0 and 1), memory in every segment, labels,
  the text segment view, the Run I/O console with input, Bitmap Display, Keyboard and Display
  MMIO, dialog syscalls as real dialogs, MIDI syscalls through your speakers, and MARS's settings
  (delayed branching, self-modifying code, memory configurations, exception handler and more).
- **Reference built in.** A searchable MIPS reference card and the original reference PDF, one
  key (F1) or tap away from the instruction under the cursor.
- **Your files.** A workspace with folders: import files, folders or a `.zip` (extracted where
  you choose), drag files and folders around, and export anything back out. Files your program
  writes through file syscalls show up in the workspace.

## New: made for phones too

- **Touch layout** with a bottom bar for the code, execution, registers, memory and console views.
- **Maximum code space.** Every panel, the line numbers and the key row can be hidden, and zen
  mode shows only the code, fullscreen.
- **Themes,** including AMOLED black.
- **Back goes back** to where you were: jumps, views and files.

## Under the hood

- **The real MARS 4.5 engine,** with the desktop GUI removed, compiled to JavaScript with TeaVM
  and run in a Web Worker. It executes about 2.5 million instructions per second in a browser,
  faster than the original desktop MARS.
- **Checked against the original.** A conformance suite runs every test program on the unmodified
  MARS 4.5 jar and on this engine, and compares output, runtime errors, instruction counts,
  registers and memory. The one known difference is documented: MARS also counts data reads
  from `.text` in its instruction count.
- **Fixed on the way:** a race in MARS's own simulator when a run is stopped, which could end a
  paused program with an error.
